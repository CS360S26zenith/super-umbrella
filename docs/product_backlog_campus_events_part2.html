Product backlog — campus event discovery platform

checkpoint Released at halfway SP = story points (Fibonacci: 1,2,3,5,8,13)
# User story SP Risk Release
Student — event discovery & browsing
US-01 As a student, I want to browse all upcoming campus events so that I can find things to attend. 3 Low checkpoint
US-02 As a student, I want to filter events by category (talks, sports, clubs, performances) so that I only see relevant events. 3 Low checkpoint
US-03 As a student, I want to search events by keyword, date, or location so that I can quickly find specific events. 5 Medium checkpoint
US-04 As a student, I want to view a detailed event page (description, time, venue, capacity) so that I have all the information I need before RSVPing. 2 Low checkpoint
US-05 As a student, I want to see personalized event recommendations based on my interests and past RSVPs so that I discover events I would otherwise miss. 13 High Final
Student — RSVP & attendance
US-06 As a student, I want to RSVP to an event so that my spot is reserved and the organizer knows I'm attending. 5 Medium checkpoint
US-07 As a student, I want to cancel my RSVP so that my spot can be freed for other students. 2 Low checkpoint
US-08 As a student, I want to see the current number of available spots for an event so that I know if space is running out. 3 Medium checkpoint
US-09 As a student, I want to join a waitlist when an event is full so that I'm notified if a spot opens up. 5 Medium Final
Student — calendar integration
US-10 As a student, I want to add an RSVPed event to my personal calendar (Google/Outlook) so that it appears in my existing schedule. 8 High Final
US-11 As a student, I want to view a calendar view of all events I've RSVPed to so that I can manage my schedule within the platform. 5 Medium Final
Student — notifications
US-12 As a student, I want to receive a notification when an event I've RSVPed to is updated or cancelled so that I'm always informed. 8 High Final
US-13 As a student, I want to receive a reminder notification before an event I've RSVPed to so that I don't forget to attend. 5 Medium Final
Club leader / organizer — event management
US-14 As a club leader, I want to create a new event with title, description, date, time, venue, category, and capacity so that students can discover and attend it. 5 Medium checkpoint
US-15 As a club leader, I want to edit an existing event's details so that I can correct mistakes or update information. 3 Low checkpoint
US-16 As a club leader, I want to cancel an event so that registered attendees are notified automatically. 5 Medium Final
US-17 As a club leader, I want to view a dashboard of my events with RSVP counts and attendance stats so that I can track engagement. 5 Medium checkpoint
US-18 As a club leader, I want to export the attendee list for an event so that I can use it for check-in or records. 3 Low Final
US-19 As a club leader, I want to send a broadcast message to all RSVPed attendees so that I can communicate important updates. 5 Medium Final
Club leader — ticket & capacity management
US-20 As a club leader, I want to set a maximum capacity for my event so that attendance does not exceed the venue limit. 3 Medium checkpoint
US-21 As a club leader, I want to generate QR-code tickets for attendees so that check-in at the door is fast and accurate. 8 High Final
LUMS staff — administration
US-22 As LUMS staff, I want to approve or reject event submissions before they go live so that only appropriate events are listed. 5 Medium Final
US-23 As LUMS staff, I want to view platform-wide analytics (total events, RSVPs, popular categories) so that I can monitor campus activity. 8 Medium Final
All users — authentication
US-24 As any user, I want to log in with my LUMS credentials (SSO) so that I don't need a separate account. 8 High checkpoint
US-25 As any user, I want my role (student / organizer / staff) to be recognized automatically after login so that I see the right interface. 5 Medium checkpoint
