CRC cards — object-oriented analysis

Each card: class name · responsibilities (left) · collaborators (right). Collaborators link to other classes.

User
Abstract entity · base class
Responsibilities
  • Store name, email, role
  • Authenticate via LUMS SSO
  • Maintain session state
  • Determine role permissions
Collaborators
  • Student
  • Organizer
  • StaffAdmin
  • AuthService
Student
extends User
Responsibilities
  • Browse & search events
  • RSVP to an event
  • Cancel an RSVP
  • Join / leave waitlist
  • View personal schedule
  • Receive notifications
Collaborators
  • RSVP
  • Event
  • Waitlist
  • NotificationService
  • CalendarService
Organizer
extends User · club leader
Responsibilities
  • Create / edit events
  • Cancel an event
  • View RSVP & attendance stats
  • Export attendee list
  • Broadcast message to RSVPs
  • Generate QR tickets
Collaborators
  • Event
  • RSVP
  • Ticket
  • NotificationService
  • StaffAdmin
StaffAdmin
extends User · LUMS staff
Responsibilities
  • Approve / reject events
  • View platform analytics
  • Manage user roles
  • Moderate content
Collaborators
  • Event
  • User
  • AnalyticsService
Event
Core domain entity
Responsibilities
  • Store title, description, date
  • Store venue, category, capacity
  • Track current RSVP count
  • Manage status (draft/live/cancelled)
  • Check if spots are available
  • Notify attendees on update
Collaborators
  • Organizer
  • RSVP
  • Waitlist
  • Ticket
  • NotificationService
  • StaffAdmin
RSVP
Association class · Student ↔ Event
Responsibilities
  • Record student–event registration
  • Store timestamp & status
  • Confirm or cancel registration
  • Trigger capacity update on event
Collaborators
  • Student
  • Event
  • Waitlist
  • NotificationService
Waitlist
Manages overflow registrations
Responsibilities
  • Add student to queue
  • Track position in queue
  • Auto-promote on cancellation
  • Notify promoted student
Collaborators
  • Student
  • Event
  • RSVP
  • NotificationService
Ticket
Check-in artifact
Responsibilities
  • Generate unique QR code
  • Link ticket to RSVP
  • Validate ticket at check-in
  • Mark ticket as used
Collaborators
  • RSVP
  • Event
  • Student
NotificationService
Service class · real-time alerts
Responsibilities
  • Send event reminders
  • Alert on event update/cancel
  • Notify waitlist promotion
  • Deliver organizer broadcasts
  • Support push / email channels
Collaborators
  • Event
  • RSVP
  • Waitlist
  • User
CalendarService
Service class · external API adapter
Responsibilities
  • Export event as .ics / iCal
  • Push to Google Calendar API
  • Push to Outlook Calendar API
  • Handle auth tokens for APIs
Collaborators
  • Student
  • Event
  • RSVP
SearchService
Service class · discovery engine
Responsibilities
  • Index events for search
  • Filter by keyword, date, category
  • Rank results by relevance
  • Support personalized sorting
Collaborators
  • Event
  • Student
  • AnalyticsService
AnalyticsService
Service class · reporting
Responsibilities
  • Aggregate RSVP & attendance data
  • Compute category popularity
  • Generate organizer dashboards
  • Provide staff platform reports
Collaborators
  • Event
  • RSVP
  • StaffAdmin
  • Organizer
